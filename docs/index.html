Features

Your library naming becomes the configuration

No database, no tagging pass, no per-file settings. The folder you already named is the whole setup.

Folder-driven language

The parent folder name decides the preferred audio track, so an existing library needs no changes at all.

Quality-aware picking

When several tracks match the language, the higher-quality codec and wider channel layout wins.

One-command install

A PowerShell script copies the Lua interface into your VLC profile and patches vlcrc, taking a timestamped backup first.

Nothing left to click

VLC loads the interface at startup, so the correct track is already selected when playback begins.

Easy to extend

Add one keyword and language pair in the Lua script to cover more of your library.

Fully reversible

The change is one copied file and one config line. Restore the backup and VLC is exactly as it was.

Install

Four steps, one of them optional

The only thing to remember is closing VLC first, because the installer edits a file VLC holds open.

1

Close VLC completely

Quit VLC and check the notification area, because the installer patches the configuration file VLC keeps open while running.

2

Clone and install

The script finds your VLC profile, copies the interface, and patches the configuration in one pass.

git clone https://github.com/Nishanth1409/vlc-folder-audio.git
cd vlc-folder-audio
powershell -ExecutionPolicy Bypass -File .\Install_FolderAudio.ps1
3

Verify with a real file

Put a video inside a folder named eng, Hindi, or Kannada and open it. The audio track should follow the folder whenever a matching track exists.

4

Extend or roll back

Add keywords in folderaudio.lua and re-run the installer. To undo everything, restore the backup the installer created.

%APPDATA%\vlc\vlcrc.bak-folderaudio-*

FAQ

Good to know

What happens when no track matches the folder?

VLC keeps its normal default track. The script only acts when it finds a language match.

Does it rename or re-encode my files?

No. It only changes which existing audio track VLC selects during playback.

Can I add more languages?

Yes. Add the folder keyword and language codes in folderaudio.lua (Tamil and Telugu are already built in), then run the installer again.

How do I uninstall it?

Restore the vlcrc backup created during install and delete folderaudio.lua from the VLC lua\intf folder.

Stop opening the audio menu

One small Lua file, one PowerShell install, and your library keeps picking the right soundtrack on its own.
